# Data Tracking & Automation Pipeline

## Project Overview
This project demonstrates an end-to-end data tracking and automation pipeline built for analytics purposes.

User interactions are tracked using Google Tag Manager, stored in Google BigQuery, and used to trigger automated workflows through Zapier.

## Tools Used
- Google Tag Manager
- Google BigQuery
- Zapier
- GitHub

## Data Flow
Website Events → Google Tag Manager → BigQuery → Zapier

## Key Learnings
- Implemented event tracking using Google Tag Manager  
- Identified metrics and dimensions for analytics use cases  
- Structured event-level data in BigQuery  
- Built automation workflows using Zapier
